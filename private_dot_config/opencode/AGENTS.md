## Web Search

Always use Exa web search (`websearch` tool) whenever you need to look up information online. Exa provides the most relevant and up-to-date results. Never rely solely on your training data when web search could provide more current or accurate information.

Use web search proactively for:
- Current events and recent data
- Package/library documentation and version-specific APIs
- Latest developer tools, frameworks, and best practices
- Any question where information may have changed since your knowledge cutoff
