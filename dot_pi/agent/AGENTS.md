Style:

- Always write code, tools, docs in English. Talk with me in Indonesia.
- Never add comments `//` of any kind in code.

Commands:

- After code changes: run the project's check/lint/type-check and fix all issues.
- Always ask before committing.
- Never run build/test unless asked.
- For ad-hoc scripts, `write` them to a temp file (e.g. `/tmp`), run verbose, edit if needed, remove when done. Don't embed multi-line scripts in `bash` commands.

Git:

- Conventional commits: `type: general`. Types: `feat`, `fix`, `docs`, `style`, `chore`, `refactor`, `test`.
- Subject line only, max 32 chars, imperative mood.
- Never create `README.md` unless asked.
